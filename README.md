# C Number Guessing Game

A simple command-line number guessing game written in C. The program generates a random number between 1 and 100, and the player must guess it using "too high" or "too low" hints.

## Features
- Generates a random number every time it runs.
- Tracks the number of attempts it takes to win.

## How to Run

1. Make sure you have a C compiler (like GCC) installed.
2. Compile the code using the terminal:
   ```bash
   gcc main.c -o game
